🧪 シニア健康サポート — スモールスタート提案

スタジオなし・大型投資なしで需要を検証し、数字でスタジオ投資の判断材料をつくる

📍 竹の塚 / イーズ / 八千代 📅 2026年4月10日 作成（保留中） 📋 全9施策 / 3フェーズ構成

背景 — なぜスモールスタートか

  • 💼 インタビューで最も切実だったニーズ — 和田ご夫妻「痛いところを聞いて、その人に合わせた準備運動やケアのアドバイスが最優先」。ばね指・肉離れ・膝痛など具体的な不具合を抱えながらテニスを続けたいシニアの声が3施設共通で浮上。
  • 🏟 しかし施設制約が大きい — 菊地コーチが指摘する通り、本格的にやるにはスタジオ整備が必要。現状はテニスコートとフロントしかなく、コーチのレッスンは詰まっており、フロントも1人体制の時間帯あり。外部トレーナー常駐の予算感でもない。
  • ❤️ 方針: まず小さく試して数字をつくる — 既存スペースと最小限のリソースで需要を検証。参加率・継続率が基準を超えたら、専用スタジオ投資の稟議材料にする。

Phase 1 — 今すぐ始められる（月5〜10万円）

専用スペース不要 / 既存コート・ロビーで完結

❶ コートサイド15分ウォームアップ

レッスン開始30分前に、コート端で「痛みヒアリング → 個別ストレッチ」を実施。和田さんが最も求めていた「テーラーメイドな準備運動」を最小構成で実現。

場所テニスコート端（カーペットコート上でそのまま）
人員外部トレーナー 月4〜8回（1回2時間）非常勤契約
コスト月5〜10万円
頻度週2〜3回 / 1回15分 / 3〜5名
収益無料（会費内）or 月額500円オプション

懸念点と対策

  • ⚠️ 医療行為との線引き — トレーナーが「診断」や「治療」に踏み込むと法的リスク。
    → 対策: 事前に「予防的アドバイスの範囲」を文書化し、トレーナーと合意。「痛みが強い場合は整形外科の受診を勧める」フローを明確にする。免責同意書の署名を初回参加時に取得。
  • ⚠️ 参加者の個別差で15分に収まらない — 痛みの部位・程度が人によって大きく異なり、時間超過でレッスン開始に支障。
    → 対策: 初回のみ事前ヒアリングシート（痛み部位・既往歴）を記入してもらい、当日は確認のみ。3パターン程度のメニューを事前に用意し、個別対応の幅を限定する。
  • ⚠️ 外部トレーナーの質のばらつき — 非常勤契約のため、担当者が変わると一貫性が失われる。
    → 対策: 最初の1〜2ヶ月は同一トレーナーに固定。SDC側で「メニューテンプレート」を作り、誰が担当しても同じ品質を担保。2ヶ月目に会員アンケートでトレーナー評価。

❷ シニアリーダー養成（会員 → 会員のサポート）

健康意識の高い常連シニア会員を「健康サポーター」に養成（月1回の外部講師研修）。彼らが月2〜3回、簡易体操・ストレッチ教室をロビーやコート端で自主開催。千葉市のシニアリーダー事業をモデルに、コミュニティの力でオペレーション負荷を分散。

場所ロビーまたはコート一角
人員外部講師 月1回の研修（5千〜1万円/回）+ 養成されたシニアリーダー
コスト月0.5〜1万円（講師謝金のみ）
頻度リーダー主導教室 月2〜3回 / 1回15〜20名
収益無料（コミュニティ育成）

懸念点と対策

  • ⚠️ リーダー候補が見つからない / 途中離脱 — ボランティア的な役割のため、負担感から辞退・離脱のリスク。
    → 対策: まず施設長・フロントから「この人なら」と思う2〜3名に声がけ。リーダー特典（月会費割引、専用Tシャツ）でモチベーション維持。最低2名体制でバックアップ確保。
  • ⚠️ 安全責任の所在が曖昧 — リーダー主導の教室中に参加者がケガした場合、誰が責任を負うか。
    → 対策: 施設の既存スポーツ保険の適用範囲を確認。リーダー向けに「やっていいこと・やってはいけないこと」チェックリストを作成。高負荷の動きは一切含めない（椅子座位体操・軽いストレッチに限定）。
  • ⚠️ 教え方の質がリーダーによって異なる — 独自アレンジが入り、安全でないメニューが混入するリスク。
    → 対策: 動画付きの標準メニュー（10分版・15分版）を作成し、リーダーはそれに沿って進行する形に。月1回の外部講師研修時にメニューの見直し・更新。

❸ 朝の空きコート体操教室（週1回・30分）

レッスン前の朝7〜8時台にコート一角で体操教室。椅子座位体操や軽いステップ運動など、介護予防の定番メニューを実施。インドア環境で天候リスクゼロ。シルバークラス新設（秋予定）の先行マーケティングとしても機能。

場所テニスコート端
人員シニアリーダー or 非常勤インストラクター（週1回1.5時間）
コスト月2〜4万円（インストラクター場合）/ ほぼゼロ（リーダー場合）
頻度週1回 / 30分 / 10〜20名
収益無料（会費内）or 月額1,500円

懸念点と対策

  • ⚠️ 早朝のスタッフ配置・施設開錠 — 通常の営業開始前の時間帯だと、施設の鍵開け・空調・照明の人員が必要。
    → 対策: 既存の最早レッスン枠の30分前に設定し、通常営業の延長として運用。施設の開館時間を変える必要がない時間帯を選ぶ。
  • ⚠️ 参加者が習慣化するまでの3ヶ月の壁 — 最初は物珍しさで来るが、2〜3週で参加者が激減する可能性。
    → 対策: 「8回出席カード」を配布し、8回達成でミニ景品（ストレッチバンドなど）。フロントから来館時に「明日は体操の日ですよ」と声がけ。最初の3ヶ月は完全無料にして習慣づけに集中。
  • ⚠️ 八千代は冷暖房なし — 菊地コーチの指摘通り、夏場は厳しい。
    → 対策: 八千代は10〜5月の秋冬春限定、夏場は休止と割り切る。竹の塚・イーズ（冷暖房あり）は通年実施で施設間の差を補完。

Phase 2 — 1〜2ヶ月後（月10〜15万円追加）

フロント横の小スペースを活用 / Phase 1の手応えを見て開始

❹ 月1回の体力測定 & 健康相談会

フロント横やロビーで握力・片足立ち・歩行速度などを簡易測定し、3ヶ月ごとに個別フィードバック。「数字で見える変化」は継続モチベーションの鍵。カーペットコートでの膝改善（ヒアルロン酸注射間隔の延長）をデータで可視化できれば、施設の訴求力が格段に上がる。

場所ロビーまたは会議室（10㎡程度）
人員保健師 or トレーナー資格者（月1回4時間）+ フロント補助
コスト月2〜3万円（講師謝金）+ 器材 約5千円（握力計・タイマー・巻尺）
頻度月1回 / 2〜3時間 / 20〜30名対応
収益無料（会費内）or 1回1,000円

懸念点と対策

  • ⚠️ 測定結果を「医学的判断」と誤解されるリスク — 数値を渡すと「異常値かどうか」を施設に問い合わせる会員が出る。
    → 対策: フィードバックシートに「この測定は健康管理の目安であり、医学的診断ではありません」を明記。基準値は厚労省の体力テスト基準表を参考に、あくまで「前回との変化」にフォーカスした記載にする。
  • ⚠️ 健康情報の個人情報管理 — 測定結果は要配慮個人情報に該当する可能性。
    → 対策: 紙の記録は会員本人に渡し、施設側は匿名化した集計データのみ保持。デジタル管理する場合はスプレッドシートにパスワードロック。プライバシーポリシーを掲示。
  • ⚠️ フロント1人体制の日に重なる — 測定会の日にフロント補助が必要だが人員が足りない。
    → 対策: 測定会はフロント2名体制の曜日に固定。あるいは外部講師に受付・誘導まで含めて委託し、フロント負荷をゼロにする。

❺ ケガ予防コンディショニング個別相談（月2回）

理学療法士がフロント横の小スペース（2〜3㎡）で1人30分の個別相談。ばね指・膝痛・肉離れなど和田さんが挙げた具体的不具合への対処法を指導。予約制で1回あたり4〜6名、フロント業務への影響を最小化。

場所フロント横の相談スペース（2〜3㎡）
人員理学療法士 or スポーツトレーナー（月4回、1回2時間、非常勤）
コスト月4〜6万円 + 器材 約1万円（ストレッチポール、テニスボール等）
頻度月2回 / 1回30分 × 4〜6名
収益1回1,500〜2,000円（都度課金）

懸念点と対策

  • ⚠️ 理学療法士法との抵触リスク — 理学療法士が医師の指示なく「治療」を行うと法律違反。施設内で「リハビリ」と謳うのもグレー。
    → 対策: 名称は「コンディショニング相談」「セルフケアアドバイス」とし、「治療」「リハビリ」の語を一切使わない。メニュー内容も「セルフマッサージの方法」「ストレッチの選び方」など、あくまで自己管理の支援に限定。契約書にも業務範囲を明記。
  • ⚠️ 予約枠が埋まらない / 逆に殺到する — 月2回×6名=12枠で、需要が読みにくい。
    → 対策: 初月は無料体験として広く案内し、需要量を実測。枠が余れば月1回に縮小、殺到すれば月4回に拡大と柔軟に調整。予約はフロントの電話 or LINEで簡易管理。
  • ⚠️ 相談スペースのプライバシー確保 — フロント横だと他の会員に内容が聞こえる。痛みや身体の悩みを話しにくい。
    → 対策: パーティション or カーテンで簡易的に仕切る（数千円）。相談時間はフロントが比較的空いている時間帯（午前中の中間枠など）に設定。

❻ シルバークラス内「個別ケア記録」連動

菊地コーチの秋以降シルバークラス新設に合わせ、フロントで「痛み・ニーズ記録表」を管理。クラス内でコーチが個別ヒアリング → 記録 → 次回反映のサイクルを回す。コーチ教育として「ボディリーディング」の簡易研修を1回実施。

場所テニスコート（シルバークラス内）
人員既存コーチ + フロント（記録管理）
コストほぼゼロ（記録シート印刷代のみ）/ 研修1回 2〜3万円
頻度週1〜2回のシルバークラスに組み込み
収益既存レッスン料に含む（追加料金なし or +500円）

懸念点と対策

  • ⚠️ コーチの業務負荷増加 — レッスンが既に詰まっている中、ヒアリング・記録の時間が取れない（鈴木施設長指摘の共通課題）。
    → 対策: ヒアリングはレッスン開始前の5分間のみ。記録はチェックボックス式（膝/肩/腰/手首 + 程度3段階）でフリーテキスト不要に。フロントへの記録受け渡しはレッスン後にカゴに入れるだけ。
  • ⚠️ コーチのスキル不足で不適切なアドバイス — テニスコーチは医療・リハビリの専門家ではない。善意のアドバイスが逆効果になるリスク。
    → 対策: コーチが行うのは「ヒアリングと記録」と「ストレッチメニューの選択（事前作成済みの3パターンから）」のみ。判断が難しいケースは「次回の個別相談（❺）を予約しませんか」と繋ぐ。研修で「やらないことリスト」を明確に共有。
  • ⚠️ 記録が蓄積するだけで活用されない — 書いて終わりになり、会員へのフィードバックに繋がらない。
    → 対策: 3ヶ月ごとにフロントが記録を集計し、「あなたの膝の痛みスコアはこう変化しました」という簡易レポートを渡す。体力測定（❹）と組み合わせれば一石二鳥。

Phase 3 — 3〜6ヶ月後（検証結果を見て判断）

Phase 1〜2の数字が出てから着手 / スケールアップ or 撤退の意思決定

❼ オンライン健康セミナー（月1回・Zoom）

栄養士・理学療法士による30〜60分の会員限定配信。テーマ例: 「膝痛とテニス」「シニアのスポーツ栄養」「転倒予防フットワーク」。施設に来れない日も接点を維持。アーカイブ視聴で価値が蓄積。

場所オンライン（Zoom）/ フロントから配信も可
人員外部講師（1回1.5〜2万円）+ 配信サポート1名
コスト月2〜3万円（講師謝金 + Zoom Pro月額）
頻度月1回 / 30〜60分 / 30〜50名同時参加
収益無料（会費内）or 1回500円

懸念点と対策

  • ⚠️ シニア層のデジタルリテラシー — Zoomの操作に不慣れな会員が多い可能性。参加ハードルが高く、せっかくの企画が空振りに。
    → 対策: 初回は施設内で「Zoom練習会」（15分）を開催。QRコードから参加できるリンクをLINEで送る形に。フロントで「やり方がわからなければお電話ください」と案内。最初の3回は施設内のモニターでも同時上映（ハイブリッド形式）。
  • ⚠️ 医学情報の正確性と責任 — 講師が誤った健康情報を発信した場合、施設の信用問題に。
    → 対策: 講師選定時に資格・経歴を確認。セミナー冒頭に「個別の医学的判断は主治医にご相談ください」のディスクレーマーを表示。可能であれば資料の事前レビューを実施。
  • ⚠️ 継続的なテーマ設定が枯渇する — 月1回だと12テーマ/年必要。ネタ切れで質が下がるリスク。
    → 対策: Phase 1〜2で蓄積した「よくある質問・相談」をテーマ化。会員からのリクエスト投票（LINE or フロント投票箱）で需要に合わせる。外部講師を複数確保してテーマの幅を持たせる。

❽ 転倒予防バランストレーニング教室（月2回）

片足立ち・重心移動・フットワークをゲーム的に実施。テニスパフォーマンス向上と介護予防を同時に訴求。自治体の介護予防事業との連携・助成金活用の可能性あり。カーペットコートなら転倒時の安全性も高い。

場所テニスコート一角（カーペットコート推奨）
人員理学療法士 or シニアフィットネス指導資格者（月2回2時間）
コスト月3〜5万円
頻度月2回 / 1回40分 / 8〜12名
収益無料（会費内）or 月額2,000円

懸念点と対策

  • ⚠️ トレーニング中の転倒事故 — バランス運動は本質的に転倒リスクを伴う。シニアが転んで骨折した場合の責任問題。
    → 対策: カーペットコート限定で実施（衝撃吸収）。壁際・手すり近くで行うメニュー設計。参加者の体力レベルを事前スクリーニング（片足立ち5秒未満の方は椅子を使う別メニュー）。スポーツ保険の適用を確認・加入。
  • ⚠️ 参加者の体力差が大きい — 70代で元気な方と80代で杖の方が同じクラスでは成り立たない。
    → 対策: 「アクティブ」「ゆったり」の2段階に分け、最初はアクティブのみで開始。ゆったり版は需要が確認できてから追加。❹の体力測定結果をクラス分けの参考にする。
  • ⚠️ 自治体助成金の手続きが煩雑 — 申請書類・報告書・要件が多く、小規模施設には負担。
    → 対策: 助成金はあくまでボーナスと割り切り、助成なしでも収支が成立する設計にする。まず自主事業で実績を作り、2年目以降に自治体の介護予防委託事業への応募を検討。

❾ 年2回「健康テニスフェスティバル」

体操教室 + テニス体験 + 体力測定 + 栄養相談 + 懇親会を1日に集約。Phase 1〜2で蓄積したコンテンツの「お披露目」として機能。非会員の集客チャネルにもなり、シルバークラスへの入会導線に。

場所テニスコート全面 + ロビー
人員企画・運営スタッフ 4〜6名（イベント当日）
コスト1回5〜15万円（講師謝金・飲食・PR費）
頻度年2回（春・秋）/ 参加者30〜50名
収益参加費2,000円（軽食込み）

懸念点と対策

  • ⚠️ 通常レッスンの休講が必要 — コート全面を使うと、当日の既存レッスンを休講にしなければならず、既存会員の不満に。
    → 対策: 既存レッスンが少ない日曜午後や祝日に設定。あるいはコート1面のみ使用 + ロビーで残りのプログラムを回す「ハーフ開催」形式に。既存会員には「イベント優先招待」で不満を軽減。
  • ⚠️ 非会員集客の見込みが不透明 — テニス施設に縁のないシニアが「健康フェスティバル」で来るかどうか。
    → 対策: 菊地コーチが計画中の「病院・公共施設へのチラシ配布」と連動。地域の包括支援センター・公民館にも告知協力を依頼。初回は既存会員＋その友人の「お連れさま枠」から始め、口コミ経由の集客を基本線にする。
  • ⚠️ イベント後の入会導線が弱い — 楽しかったけど終わり、で次に繋がらない。
    → 対策: イベント参加者限定の「シルバークラス2回無料体験チケット」を配布。その場で体験予約まで取る導線を設計。アンケートでLINE登録を促し、後日フォローメッセージを送信。

📏 検証の判断基準

Phase 1〜2を3ヶ月間計測し、スタジオ投資の可否を判断

Go / No-Go 基準

指標 Go（スタジオ投資検討へ） No-Go（コート内運用に留める）
月あたり延べ参加者数 50名以上 30名未満
リピート率（2回以上参加） 60%以上 40%未満
